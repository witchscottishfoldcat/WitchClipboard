Witch Clipboard 1.9.0 增加快捷键迷你面板与保留原窗口焦点设置，修复已复现的菜单焦点粘贴失效，并补齐历史管理和同步的一致性。

### 面板与粘贴

- 设置 → 行为新增「主快捷键打开迷你面板」：开启后，主快捷键（默认 `Alt+V`）打开迷你面板，单击托盘打开完整面板；独立 `Alt+M` 保留。[Issue #1](https://github.com/witchscottishfoldcat/WitchClipboard/issues/1)
- 新增「呼出时保留原窗口焦点」，默认关闭。开启后键盘输入继续留给原应用，点击面板后再搜索、用方向键选择或按回车粘贴；点击面板外收起。[Issue #2](https://github.com/witchscottishfoldcat/WitchClipboard/issues/2)
- 修复目标应用处于菜单/Alt 访问键焦点时，迷你面板双击和回车粘贴失效；过滤任务栏、托盘、桌面粘贴目标，并检查按键注入结果。[Issue #3](https://github.com/witchscottishfoldcat/WitchClipboard/issues/3)
- 最小化目标先还原，等待目标成为前台再粘贴；管理员窗口无法接收自动粘贴时给出明确提示。

### 历史管理

- 条目可绑定持久全局热键；支持层级分组与重命名、备注搜索、多选顺序粘贴、文本变换，以及 JSON 历史导入导出。
- 设置页提供单条内容大小上限：1 MB / 20 MB / 100 MB / 不限。
- 剪贴板采集增加静止窗口、短暂读取失败重试、来源归因与监听看门狗，修复敏感排除标记的竞态。

### 数据与同步修复

- 导入前校验全部条目的版本、类型、哈希和图片内容，拒绝非法 Blob 路径与哈希。
- WebDAV 元数据使用独立版本合并，旧快照不会覆盖刚修改的备注、标签、置顶、热键和分组；区分缺失字段与明确清空，保持旧客户端兼容。
- 同步后刷新热键注册与界面；分组重命名、导入和部分同步失败后的变化也能及时显示。
- 数据库升级到 v8，迁移前自动创建并校验加密备份。

提供 Windows x64、ARM64 安装包与便携包。安装包附带 updater 签名，`latest.json` 支持两种架构；下载后可使用 `SHA256SUMS.txt` 校验文件。
